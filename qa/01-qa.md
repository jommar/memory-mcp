   constant; line 80 already asserts the real behavior. Simplify to a literal.

   in both test/db/relational-schema.test.ts:50 and test/db/vector-schema.test.ts:33 (items 3
   and 4 each carried their own copy). Keep one owner.

   test name; titles should describe observed behavior, doc refs belong to the plan.

   'distance_metric=cosine'`; acceptable here because the same file also proves behavior
   (insert/KNN/reject), and "exists post-migration" is most directly asserted via DDL.
5. **Column-order strictness** — relational-schema.test.ts uses exact-order `toEqual` on
   PRAGMA table_info; stricter than DESIGN §4 (order unspecified) but stable under the
   forward-only migration contract. Harmless.

   ModelLoader (external network/model boundary) and fakeProvider at the provider
   interface; all DB behavior runs against real better-sqlite3 handles. No mocks beyond
   system boundaries, no implementation-coupled white-box tests, no shared mutable state
